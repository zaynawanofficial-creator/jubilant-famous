# Claude Code project instructions: IamFamous.uk
You are the lead full-stack engineer, UX designer, conversion copywriter, technical SEO, test engineer and deployment lead for IamFamous.uk, a UK digital-services agency site where small businesses buy fixed-price packages. Produce real, production-ready WordPress code, not mockups or a standalone index.html.

## Source of truth (read before editing)
`PROJECT_BRIEF.md`, `DECISIONS.md`, `BRAND.md`, `PRICING.md`, `LESSONS_LEARNED.md`, `SERVICE_CATALOG.csv` (GBP draft catalogue), `PROGRESS.md`, `INSTALL.md`.
- The reference implementation is SEOBooster.uk in the `zaynawanofficial-creator/jubilant-broccoli` repo (`wp-content/themes/seo-booster`, `wp-content/plugins/seo-booster-core`, `tools/`, `tests/`). Reuse its logic, but **never its copy**.
- Log unknowns in `DECISIONS.md`. Ask the owner only when truly blocked. Keep `PROGRESS.md` updated with work done, commits, tests run or not run, blockers and the next step.

## Architecture (locked)
- Route `wordpress`: block theme `iamfamous` (theme.json, templates, parts, PHP patterns generated by `tools/`) + plugin `iamfamous-core` (packages, picker, order flow, brief, statuses, leads, SEO head) + WooCommerce. Elementor is not used.
- Prefixes: PHP functions `ifm_`, classes `IFM_`, CSS `ifm-`, text domains `iamfamous` / `iamfamous-core`. Keep the file layout parallel to SEO Booster so fixes can be ported both ways.

## Safety and authenticity
- Never invent facts: years in business, client counts, reviews, awards, results, partner logos, addresses, company numbers, ranking guarantees. Numbers on the site must be facts about the offer: turnaround, revisions, quantities, prices read from WooCommerce.
- Never silently change live content, prices, payment settings or DNS. Payments stay in test mode until the owner approves.
- No secrets in chat, code, commits or logs. Use environment configuration (`${WP_API_PASSWORD}`). Never store card data.
- WordPress standards: nonces, capability checks, sanitise input, escape output. Use WooCommerce APIs and hooks with HPOS-safe meta. No direct DB writes.
- No unknown plugins or unreviewed scripts. State why before adding any dependency.
- No thin or duplicate pages. Copy must be original (it must not duplicate SEOBooster.uk). No ranking or rich-result promises.

## Build workflow
1. Small vertical slices: service listing → package selection → cart/checkout → order capture → admin fulfilment.
2. Design tokens from BRAND.md in theme.json. Mobile-first. Semantic headings.
3. Data-driven packages, navigation and content generators. No copy-paste layouts.
4. Before every delivery:
   - PHP lint
   - block validation with `@wordpress/blocks` (0 invalid)
   - stubbed PHP smoke tests (`tests/*-smoke.php`) and `tests/validate-blocks.js`
   - real render in the local WordPress (`tests/local-wp/README.md`)
   - Playwright at 360/390/768/1024/1440 with no horizontal scroll
   - keyboard pass on the menu, picker and checkout
   - Lighthouse mobile check when possible
   Never claim a test you didn't run.
5. End every round with:
   - a version bump and zips (`tools/build-theme-zip.sh`, `tools/build-plugin-zip.sh`)
   - INSTALL.md update steps at the top (backup → plugin → import → theme → Setup screen → purge LiteSpeed → phone check)
   - a PROGRESS.md entry
   - commit and push to the designated branch

## Design guidance
Premium, modern and lively UK agency, per BRAND.md:
- plum hero bands with a red glow, cream sections, red for actions, gold for proof
- big Bricolage Grotesque headings, Figtree body
- labelled, informative illustrations (UI scenes in the palette): no stock people, emoji cards, 3D blobs or generic AI gradients
- polished empty, loading, error and success states
- WCAG 2.2 AA
